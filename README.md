# Odd or Even:
A Python program that identifies whether the number you have inputted is odd or even.

## How to Run
1. Open 'prac_exercise.ipynb',
2. Run the program,
3. Enter a number

## Modules used
if, else, modulo %

## Functions
if - checks whether the number inputted is even,
else - identifies the number as odd if it did not meet the if requirements,
modulo % - checked if the number was divisible by 2
